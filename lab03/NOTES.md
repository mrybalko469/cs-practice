# Воркшоп по Git (lab03)

## 2. Сравнение версий и поиск изменений

- `git log --oneline --stat` — список коммитов в одну строку и какие файлы в каждом изменились и на сколько строк. Нужен, чтобы увидеть историю целиком.
- `git diff HEAD~2 HEAD -- lab03/calc.py` — разница между двумя состояниями файла: между первым и третьим коммитом добавились функции `sub` и `mul` и ветки `elif` для `-` и `*`.
- `git show HEAD~1` — один конкретный коммит: автор, дата, сообщение и его изменения (добавление вычитания).
- Отличие: `git diff` сравнивает два произвольных состояния (коммиты, рабочую папку, индекс); `git show` показывает один коммит и его изменения; `git log` показывает историю коммитов, а не содержимое изменений.
- `git log -S"def" --oneline -- lab03/calc.py` — ищет коммиты, где менялось число вхождений строки `def`. Нашёл три коммита, где добавлялись функции `add`, `sub`, `mul`.
- `git blame lab03/calc.py` — для каждой строки показывает, каким коммитом и кем она последний раз изменена. Видно, что строки с `mul` пришли из коммита про умножение.
