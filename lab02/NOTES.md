# Заметки о Git
## Локальные состояния
Рабочая папка — это файлы проекта, которые я сейчас просматриваю и изменяю.
Индекс — промежуточная область, куда командой git add помещаются изменения, подготовленные для следующего коммита.
Коммит — сохранённый снимок подготовленных изменений с автором, датой и сообщением
## Git и GitHub
Git — программа для контроля версий, которая хранит историю проекта и позволяет работать с ней локально.
GitHub — интернет-сервис для размещения Git-репозиториев, совместной работы и публикации истории изменений.
