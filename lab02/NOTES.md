# Заметки о Git
## Локальные состояния
Рабочая папка — это файлы проекта, которые я сейчас просматриваю и изменяю.
Индекс — промежуточная область, куда командой git add помещаются изменения, подготовленные для следующего коммита.
Коммит — сохранённый снимок подготовленных изменений с автором, датой и сообщением
## Git и GitHub
Git — программа для контроля версий, которая хранит историю проекта и позволяет работать с ней локально.
GitHub — интернет-сервис для размещения Git-репозиториев, совместной работы и публикации истории изменений.
## Использованные команды
- git status показывает состояние рабочей папки и индекса.
- git diff показывает изменения рабочей папки, ещё не добавленные в индекс.
- git diff --staged показывает изменения, добавленные в индекс для следующего коммита.
## Ветки
Ветка — это отдельная линия разработки и указатель на определённый коммит.
При создании нового коммита текущая ветка передвигается на этот коммит.
Слияние объединяет изменения одной ветки с другой. При слиянии с параметром --no-ff создаётся отдельный коммит слияния.
